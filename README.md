# ecommerce-timor-leste

Platform e-commerce (multi-vendor marketplace) ba Timor-Leste, ho website ba kliente, painel admin, backend API, no aplikasaun mobile ba motorista entrega.

## Estrutura

- `frontend-ecommerce/` — storefront ba kliente (Next.js)
- `admin-panel/` — dashboard administrasaun (Next.js)
- `backend-services/` — API backend (NestJS + Prisma)
- `driver_app/` — aplikasaun mobile ba motorista entrega (Flutter)
